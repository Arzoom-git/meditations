# 沉思錄

馬可・奧理略《沉思錄》十二卷、四百八十七則的閱讀 App。一次讀一則，每則附名詞解釋與閱讀理解。

打開：https://arzoom-git.github.io/meditations/

在 iPhone 的 Safari 按分享鈕，選「加入主畫面」，就能從桌面打開，沒有網路也能讀。收藏與閱讀進度只存在你自己的裝置上。

## 內容來源

- 底本是 George Long 的英文譯本（1862 年，公版），取自 Project Gutenberg 第 15877 號電子書。
- 中文譯文與閱讀理解由 AI 依這個英文底本產生，沒有經過專業譯者逐則校對，可能有錯。原文殘缺的地方以「……」或〔 〕標示。
